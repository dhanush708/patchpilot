PatchPilot

Verification-driven auto-patching for Python repositories

What PatchPilot Does

  • Runs pytest automatically
  • Applies safe deterministic fixes
  • Stops on unsafe or semantic changes
  • Never loops infinitely

Limitations

  • Python repositories only
  • .zip uploads only (.rar blocked)
  • pytest tests required
  • No internet during execution
  • Complex logic requires human fix
